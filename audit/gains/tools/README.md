## Toolchain installed for the builds

- rustup-init from https://win.rustup.rs/x86_64, run `-y --profile minimal --no-modify-path` (PATH not modified). Toolchains: `stable-x86_64-pc-windows-msvc` (rustc 1.99.1, cargo 1.99.1) and `nightly-2025-09-20-x86_64-pc-windows-msvc` (pinned by aderyn's rust-toolchain.toml). Binaries in `~\.cargo\bin`.
- `cargo install aderyn` from crates.io resolves to the stale 0.1.9 crate and fails to build (duplicate `SOLC_VERSION_0_8_35` in svm-rs-builds); do not use it.
- Downloaded archives are under `~\tools\dl\<name>\`, build and smoke logs under `~\tools\dl\*.log`.
