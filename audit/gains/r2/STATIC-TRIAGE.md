## Method

1. Build into a private dir (no forge lock needed: the worktree's `out/` and `cache/` are not touched):
   `forge build --build-info --skip "./test/**" "./script/**" --out <scratch>/out --cache-path <scratch>/cache`.
2. **Tooling note (Slither crash).** `slither . --ignore-compile --foundry-out-directory <scratch>/out --filter-paths
   "lib/|test/|script/|src/[A-Z]|src/hypercore|src/libraries"` aborts on the current tree with
   `AssertionError` in `slithir/convert.py reorder_arguments` while generating IR for `GainsVaultFactory.create`, after
   "Function not found setPairFeed / setSequencerFeed" for GainsVault. Cause: two structs named `InitParams` and two
   named `VaultStorage` exist in one compilation unit (`src/VaultTypes.sol`, round 4, and `src/gains/GainsTypes.sol`);
   Slither resolves the named-argument struct literal `InitParams({...})` (19 fields) and `$.policy` against the round 4
   struct. Workaround used: a scratch copy of `contracts/` in which only the round 4 files outside `src/gains`
   (`src/*.sol`) have the two structs renamed (`HVStorage`, `HVInitParams`); `src/gains` is byte-identical to the
   worktree (`diff -r` clean), and line numbers of every gains file are unchanged. Not a contract issue: the two
   structs never meet in one contract. A future round should keep this workaround (or rename one struct in the source).
3. Slither in the scratch copy, all detectors, JSON output (58 contracts, 102 detectors, 199 results).
4. Aderyn: `aderyn . --src src -i gains -o <scratch>/aderyn-gains.json` in the worktree (reads sources only; no build).
5. Diff against round 1 (`tools/SLITHER-TRIAGE.md`, `tools/ADERYN-TRIAGE.md`) by script: a result matches a round 1 row
   when detector and every flagged code text are equal ("unchanged" if the line is equal too); otherwise by detector and
   function ("lines moved"). Round 1 triage is carried for those after re-reading the code; a carried reason is quoted verbatim, so line numbers inside it are round 1's (the location column is current). Every other result was
   triaged by hand. Slither lines are recomputed from the solc byte offsets against the LF-normalised file (the files
   are CRLF; Slither's own line numbers drift), as in round 1. Scripts: scratchpad `stat/extract.py`, `match.py`,
   `aderyn_match.py`, `gen.py` (not committed).

Severity of the triage labels: **finding** = a contract issue that needs a GR2 id and a PoC; **informational** = true
observation, no security impact, or by design; **false positive** = the detector's premise does not hold.
